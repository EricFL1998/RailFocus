# Rail Focus 2.1

让每一次专注更像一段正在发生的旅程：地图更有生命感，操作更有回应，专注页更安静、更有秩序。

## 全新视觉与地图

- 锁定品牌铁道绿，浅色与深色主题保持一致的产品气质。
- 地图配色与层次重新调校：浅色更温暖，夜间更清晰，铁路与水系更容易辨认。
- 路线加入柔和的三层辉光，让前进轨迹更醒目。
- 首页增加随时间变化的氛围色温；位置卡片采用更清晰的出发信息牌样式。

## 更安静的专注页

- 倒计时成为唯一视觉主角，配合简洁的行程进度线与起终点信息。
- 暂停与更多操作合并为顶部居中的玻璃控件组，长时间不操作会自动降低存在感。
- 双击屏幕可进入纯净模式，只保留倒计时和行程进度；再次双击即可恢复。
- 移除途中多余站名、定位点与已行进里程，减少视觉干扰。
- 车次、车厢与座位信息移至发车前的车票确认环节。
- 设置中新增「专注页信息密度」，可选择纯净、标准或全量显示。

## 更自然的动效与天气

- 按钮按压、时长选择与目的地切换加入统一、轻快的回弹反馈。
- 目的地卡片增加细微视差与翻转动感。
- 优化雨、雪、云、雾、沙尘、晴天光晕与夜间星光的透明度、密度和边缘，天气更轻盈，不再遮挡主要内容。
- 座位选择与车票检票时自动收起天气动画，避免遮挡关键操作。
- 跟随系统「移除动画」设置，减少不必要的动态效果。

## 修复与稳定性

- 修复进入设置等页面时，天气退出动画可能导致的崩溃。
- 修复地图复用时定位标记和站点残留的问题。
- 修复长站名、行程信息与页面控件的对齐和溢出。
- 优化车票纸张质感，保留打孔、盖章与到站的仪式感。

---

本次版本不涉及数据库结构变更，旅程记录、手账与设置可在覆盖安装后保留。
