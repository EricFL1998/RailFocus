# Rail Focus「灵动感」研究与改造方案

> 研究对象：Rail Focus 2.0.1 现有 UI；对标 小鹿足迹（Retrace）、Worldo、GoLog 三款「足迹 / 旅程记录」类 App。
> 方法：46 个 UI 源文件通读（约 1.6 万行）+ 9 张 promo 截图 + 3 款竞品 App Store 官方截图逐张比对 + 既有设计文档（`docs/IMMERSIVE_JOURNEY_DESIGN.md` 等）。
> 局限：本次无真机/模拟器（`adb devices` 为空），帧率、手感、振动强度未经实测；promo 截图与 2.0.1 代码可能存在版本差（例如截图里专注页内容压到状态栏，而 `FocusSessionScreen.kt:145` 已有 `statusBarsPadding`）。结论以代码为准，视觉判断以截图为准。

---

## 0. 一页结论

**你的 App 不是「不会动」，而是「动的地方不对」。**

- 现有动效约 **80% 花在边缘装饰**上：定位点的脉冲圆环、倒计时冒号的呼吸、按钮按下的 0.96 缩放、录音时的红点脉搏。
- 而用户 **80% 的注意力** 落在三个主角上：**地图、倒计时、车票**。这三个主角目前几乎都是静态的——地图是一张哑光米色纸，倒计时是一个不透明的圆角方块，车票是一张白色卡片。
- 三个对标 App 的「灵动」并不来自更花的动效，而来自同一套公式：

> **地图当画布 + 光当进度 + 实体当奖励 + 角色当替身 + 一句话当情绪**

| 维度 | 竞品做法 | 你的现状 | 结论 |
|---|---|---|---|
| 地图 | GoLog 暗底霓虹轨迹 / Worldo 星空地球 + 像素人 | 米色极简 OSM，无地物 | 最大面积 = 最低信息密度 |
| 光 | 「点亮城市」「轨迹发光」 | 轨迹是单层 60% 透明线 | 没有能量感 |
| 实体 | 城市卡片、游记、报告 | 车票（做得好） | 已有资产未放大 |
| 角色 | Worldo 会走路的像素小人 | 只在专注时有个小三角车标 | 首页没有「谁」 |
| 语言 | 「你走过的每一条街道，都是你人生地图的一部分」 | 「开始旅程 / 我的 / 数据」 | 说明书语气 |

**按性价比排序的 5 件事（P0）**

1. 关掉默认动态取色，把品牌绿锁回来（半小时，收益最大）。
2. 地图重绘：分层色 + 三层辉光轨迹 + 当前站呼吸 + 昼夜色调层。
3. 转场从「淡入淡出」改成「容器形变 / 路线生长」。
4. 专注页加一条「窗外」纵向生命线：速度、光线、风景随进度走。
5. 车票与到站做成「实体时刻」：纸纹、压印、盖章、飞入收藏。

**同时要做减法**：现在一屏可能同时跑 3–4 个 `rememberInfiniteTransition`。灵动的反面不是静止，是「处处都在动，于是处处都不重要」。

## 1. 先把「灵动」拆成可验收的六力

「灵动」是形容词，不能直接施工。拆成 6 个可判定、可打分、可写进 code review 的维度：

| # | 力 | 一句话定义 | 自检问题 | 现状 | 目标 |
|---|---|---|---|---|---|
| 1 | **呼吸** Ambient | 没有交互时，世界仍然活着 | 静置 3 秒，屏幕上有几处缓慢变化？ | 2/5 | 4/5 |
| 2 | **因果** Causality | 每个动作都有预备—响应—回弹 | 按下之后 16ms 内有反馈吗？有回弹吗？ | 3/5 | 4.5/5 |
| 3 | **连续** Continuity | 元素在空间上不被「换掉」，而是「长成」 | A 屏的东西到 B 屏还在原位变形吗？ | 2.5/5 | 4/5 |
| 4 | **物质** Materiality | 有光、有厚度、有材质 | 界面里有几个不同的「高度」？ | 1.5/5 | 4/5 |
| 5 | **角色** Character | 画面里有一个「谁」在替你经历 | 用户会跟哪个东西产生情感？ | 2/5 | 4/5 |
| 6 | **语言** Voice | 文案与排版带情绪和节奏 | 把文字遮住，还看得出情绪吗？ | 2/5 | 4/5 |

横切维度：**节奏 Rhythm** —— 快慢对比。全是 300ms 等于没有节奏；要有 120ms 的即时反馈和 600ms 的场景转换。

> 打分方法见 §9，改造前后各打一次，用同一把尺子验收。

## 2. 竞品深读：它们到底做对了什么

### 2.1 小鹿足迹（英文名 Retrace，id6481981341）

- **定位**：全自动生活轨迹 + AI 日记，iOS 4.6 分。
- **视觉**：`#0f172a` 深蓝黑板底 + **Playfair Display 衬线大标**（`deergo.app` 的 theme-color 与字体栈可证）。深色 + 衬线 = 高级感与「日记本」气质，和你的「白纸 + 无衬线粗黑」正好相反。
- **三个可迁移机制**
  1. **被动惊喜**：用户什么都不做，App 自己产出「今天你去了哪、待了多久」。→ 你可以做「本周铁路简报」：自动生成一张海报，不用用户填任何东西。
  2. **衬线 vs 无衬线的对撞**：数字/站名用无衬线压缩体，抒情标题用衬线。你目前全部 Roboto Flex，中文还回退系统字体，层级只能靠字重堆。
  3. **「点亮世界地图」**：把「去过」变成「点亮」。你已有 33 省点亮数据（`DataBottomSheet.kt:1233`），但只以 chips 呈现。
- **不可迁移**：它是「无感记录」，你是「主动开启一段专注」，惊喜感必须来自「完成之后」，不能来自「后台」。

### 2.2 Worldo（id6792356726 / 6760472632）

- **定位**：旅程记录 + 自动游记 + 城市卡片解锁。
- **视觉**：薄荷绿渐变海报 + 星空地球 + **像素小人牵着狗走在你的轨迹上**。
- **三个可迁移机制**
  1. **替身（Avatar）**：一个会沿着你的路线走的小人，是「灵动」最强的单点。你完全对得上——**你的替身就是那列小火车**，只是现在它只在专注页出现，而且是个静态三角图标（`MapLibreView.kt:1329-1356`）。
  2. **情绪打卡**：每天一个 emoji 心情。→ 专注结束后问一句「这趟车坐得怎么样？」（😌/😤/😴），比任何数据都更能让人回看。
  3. **收集实体**：城市卡片。→ 你已有车票，缺的是「车站图鉴 / 线路图鉴」的收集维度。
- **不可迁移**：它的地图是「生活街道」，你的地图是「全国铁路网」，尺度不同——你的收集单位应该是**线路与车站**，不是街区。

### 2.3 GoLog（id6757791955）

- **定位**：低功耗足迹记录 + 地图/时间线/统计。
- **视觉**：纯黑 + 霓虹轨迹（青/紫/品红）+ 省份「点亮」填色 + 到访半径涟漪 + 四个不同高饱和色的数字分栏。
- **三个可迁移机制**
  1. **光 = 进度**：走过的路发光，没走过的暗。这是最便宜、最有效的「活」。
  2. **暗色作为主场景**：它的暗色不是「夜间模式」，是「夜行地图」这个产品人格。你的深色主题（`#0D130F` 绿黑）已经很好，但没有被当成「主场景」设计过。
  3. **彩色数字**：里程/点数/天数各用一种高饱和色，数据页立刻有节奏。你的数据页是同一套 onSurface 灰。
- **不可迁移**：它是「记录一切移动」，你是「一段被命名的旅程」，所以你的光应该集中在**一条线**上，而不是铺满地图。

### 2.4 共性公式

```
情绪入口（一句话/一张海报）
   ↓
画布（地图，且被光照亮）
   ↓
过程（一个替身在动 / 光在增长）
   ↓
实体（卡片/车票/报告，可收集、可分享）
   ↓
回访（统计 + 成就 + 回忆）
```

你 5 项都有雏形，唯独第 2、3 项（画布与过程）是静态的——所以整体「差强人意」。

## 3. 现状体检：12 条「不动」的具体证据

| # | 现象 | 证据 | 为什么不灵动 |
|---|---|---|---|
| 1 | 品牌色被动态取色覆盖 | `Theme.kt:97-105`：`dynamicColor = true`，浅色直接 `dynamicLightColorScheme`，只有深色才用品牌色 | 换张壁纸 App 就换性格，截图里的蓝色就是证据；「铁道绿」是资产，被系统随机色替代 |
| 2 | 底图是一张低对比的纸 | `MapLibreView.kt:1517-1525`：底 `#f5f0e8`、路 `#d9d1c5`、水系 `#c8dfe8`，且样式里没有 landuse / POI / 建筑 | 90% 的屏幕面积、几乎为零的信息与温度 |
| 3 | 轨迹是单层平线 | `MapLibreView.kt:1246-1254`：一条 `line`，`opacity * 0.6`，宽度固定 | 没有「能量」，不像「正在发生的事」 |

| 5 | 没有高度层级 | `LocationHeader.kt:53-54` `shadowElevation = 0`；多处 `surface.copy(alpha = 0.68~0.92)` | 全部贴在同一个平面上，卡片和地图分不开 |
| 6 | 主转场只有淡入淡出 | `HomeScreen.kt:242-247` `fadeIn(tween(300)) togetherWith fadeOut(tween(300))` | 空间关系断裂：地图留在原地，内容「换台」 |
| 7 | 无限动画散落各处 | `LocationHeader:62`、`FocusComponents:81,470,837`、`FocusSessionScreen:347`、`DataBottomSheet:323`、`TicketCheckInScreen:155,369`、`VoicePlayPill:143`、`JournalEditDialog:390` | 处处在动 = 没有焦点；同时耗电、发热、掉帧 |
| 8 | 天气像贴在屏幕上的划痕 | `WeatherAnimationOverlay.kt:47-120`：全屏 Canvas 雨丝，与地图无交互 | 雨没有「落到世界上」，没有玻璃介质、没有湿地面、没有景深 |
| 9 | 文案是说明书 | `strings.xml:5-31`：开始旅程 / 我的 / 数据 / 正在前往 | 没有情绪，也不给用户「被理解」的瞬间 |
| 10 | 字体层级单薄 | `Type.kt`：全部 Roboto Flex；中文回退系统字体 | 中文只能靠字重区分；数字没有专用字族 |
| 11 | 世界没有时间感 | 无昼夜/色温联动（仅 `isNight` 布尔影响天气层） | 20:00 和 14:00 的首页一模一样 |
| 12 | 有数字动画但缺「时刻」 | `DataBottomSheet.kt:543,624` 有 count-up；`AllJourneysScreen.kt:252-343` 有点亮省份标签 | 数据动了，但没有仪式；成就不「响」 |

**值得保留的优点（不要在改造中丢掉）**

- 共享元素转场（`sharedBounds` 的 header 与主按钮）方向是对的，只是用得不够。
- 车票的视觉语言（巨大的站名、虚线撕口、系列色）已经有辨识度，是全 App 最强的资产。
- 预测性返回、`animateItem()`、`graphicsLayer` 内读动画状态（避免重组）——工程习惯很好，改造可以放心加动效。
- 触感/音频不是从零开始：`TicketFeedbackHelper`（打孔音 + 波形振动）、`raw/` 里的报站音、白噪音。

## 4. 设计系统：把「灵动」变成 token

### 4.1 动效 token（先统一，再谈花活）

现状：`120/180/220/240/300/350/400/450/600/1000/2600ms` 散落各处，`FastOutSlowInEasing` 被用在几乎所有场合。

建议四档时长 + 四种曲线，**只允许用这 8 个值**：

| Token | 值 | 用在哪 | 曲线 |
|---|---|---|---|
| `Instant` | 90ms | 按下、勾选、切换的即时反馈 | `LinearOutSlowIn` |
| `Fast` | 160ms | 图标变形、颜色、透明度 | `CubicBezier(0.2, 0, 0, 1)` |
| `Base` | 240ms | 卡片展开、列表位移、内容替换 | `CubicBezier(0.2, 0, 0, 1)` |
| `Scene` | 480ms | 页面/场景转换、路线生长 | `CubicBezier(0.05, 0.7, 0.1, 1)` |
| `Press` | spring(d=0.55, k=900) | 按压回弹（要有轻微过冲） | — |
| `Settle` | spring(d=0.78, k=420) | 松手归位、卡片吸附 | — |
| `Float` | spring(d=0.9, k=180) | 呼吸、漂浮、跟随 | — |
| `Stagger` | 28ms × index | 列表/站点依次出现 | — |

```kotlin
// ui/theme/Motion.kt （建议新增）
object Motion {
    const val Instant = 90
    const val Fast = 160
    const val Base = 240
    const val Scene = 480
    const val Stagger = 28

    val press = spring<Float>(dampingRatio = 0.55f, stiffness = 900f)
    val settle = spring<Float>(dampingRatio = 0.78f, stiffness = 420f)
    val float = spring<Float>(dampingRatio = 0.9f, stiffness = 180f)

    fun <T> enter() = tween<T>(Base, easing = CubicBezierEasing(0.2f, 0f, 0f, 1f))
    fun <T> scene() = tween<T>(Scene, easing = CubicBezierEasing(0.05f, 0.7f, 0.1f, 1f))
}
```

> **为什么强调「过冲」**：你现在的按压是 `0.96 → 1.0`，用 `StiffnessMediumLow`（很软的弹簧）且没有阻尼过冲，观感是「慢慢缩、慢慢回」。改成 `d=0.55` 会有 2–3% 的回弹，手感立刻「弹」起来。代价是必须配 12ms 内的触感，否则像果冻。

### 4.2 三级光影（Materiality）

| 层 | 用途 | 做法 |
|---|---|---|
| **L0 纸** | 地图、背景 | 极轻噪点纹理（`drawWithCache` 生成 8% 透明噪点，只画一次）+ 顶部到底部的 3% 明暗渐变 |
| **L1 浮起** | 卡片、header | `shadowElevation = 8dp` + 1px 顶部内高光（`Brush.verticalGradient(white 0.5→0)`）+ 品牌色 8% 描边 |
| **L2 玻璃** | 专注页计时器、底部操作条 | `Modifier.blur(24.dp)` 的内容副本 + `surface.copy(alpha = 0.55f)` + 上缘 1px 高光；`minSdk = 31`，可以放心用 `RenderEffect` 真模糊 |

现在的问题不是「没有阴影」，是**所有东西都在 L0.5**：既有 alpha 又有 3dp 阴影，既不像纸也不像玻璃。**要么贴地，要么浮起，不要中间态。**

### 4.3 色彩能量（Color Energy）

按面积分配，而不是按组件分配：

- **90% 中性**：纸色 / 墨色（地图、正文、留白）
- **8% 品牌**：铁道绿 `#2E7D32` 只出现在「正在进行」的元素上（当前站、计时、进度）
- **2% 高能**：只给三个时刻——出发、到站、成就。用 `#F2A93B`（信号黄）或 `#D9432F`（信号红）。

三条硬规则：

1. **一个屏幕最多一个高能色**。现在专注类型的六种糖果色（`FocusTypeSelectionPopup`）本身没问题，但不能同时出现在首页。
2. **暗色是「夜行模式」，不是「夜间模式」**：`#0D130F` 底 + 轨迹发光 + 站点星点。把暗色当成一个正式的视觉场景去做，而不是把浅色反相。
3. **动态取色默认关闭**，或做品牌化调和：取系统色的色相但把饱和度/色相拉到绿系 ±30° 以内。如果一定要保留动态取色，至少在 `RailFocusTheme` 里加一个「品牌优先」开关，默认品牌。

### 4.4 角色系统（Character）

Worldo 证明：一个会动的替身胜过十个动效。

- **主角色：那列小火车**。它现在只在专注时出现，且是静态三角。建议：
  - 首页：停在「你的当前站」上，怠速时轻微上下浮动（±1.5dp，2.4s，`Float` 弹簧），车头灯有一束 8% 透明度的光锥指向上次的终点。
  - 选完时长：列车沿预览路线「试跑」一小段再回到站台（180ms + 400ms），暗示「这趟能到哪」。
  - 专注中：沿真实线路前进（已有），加**车轮/受电弓微动**与**到站减速**。
  - 到站：车头灯闪两下 + 车票盖章。
- **副角色（可选）**：一只在站台上等你的小鹿/信号灯精灵，只出现在空状态与成就页，负责说「人话」。
  > 注意：角色一旦引入就必须有「不做作」的出场节奏，否则会变成吉祥物灾难。建议先只做列车，验证情感反馈后再加第二个。

### 4.5 声音与触感 token

你已经有素材，缺的是「分级」：

| 事件 | 触感 | 声音 |
|---|---|---|
| 切换时长档位 | 8ms 轻点（`VibrationEffect.createOneShot(8, 60)`） | 无 |
| 选中目的地 | 12ms + 4ms 双击 | 无 |
| 开始旅程 | 18ms 单次 | 发车提示音（已有 `train_departure_announcement`） |
| 打卡/盖章 | 波形 8-12-18ms（已有） | 打孔声（已有 `ticket_punch`） |
| 到站 | 波形 20-60-20ms | 到站报站（已有） |
| 成就解锁 | 三段渐强 | 无（用画面） |

原则：**同一类事件全 App 只用一种触感**。现在「按钮」全部用 `LongPress` 触感（`HomeScreen.kt:561`），这是「长按」的语义，用错了，应该换成 `TextHandleMove` 或自定义轻点。

### 4.6 文案三档语气

| 档 | 场景 | 例 |
|---|---|---|
| **报告体**（现状） | 设置、确认、错误 | 「提前结束会生成一张未完成的旅程车票」— 保留，很好 |
| **同行体** | 空状态、引导、加载 | 「列车还没发车，先挑一段路吧」 |
| **纪念体** | 完成、到站、成就 | 「21:37，你从双鸭山西抵达桦南东。这 64 公里，是你今天为自己留的。」 |

只需要改 30–50 条字符串，收益极高。参考小鹿足迹的「你走过的每一条街道，都是你人生地图的一部分」——它没有增加任何功能，只是把功能说成了人的事。

## 5. 逐屏处方

### 5.1 首页（`HomeScreen.kt` + `LocationHeader.kt` + `MapLibreView.kt`）

**现状**：米色空地图 + 左上胶囊 header + 底部三个胶囊按钮。信息架构没问题，问题全在「世界是死的」。

1. **地图重绘（P0，收益最大）**
   - 浅色：底 `#F3EEE4`，水系做**垂直渐变**（浅蓝→更浅），陆地加一层 2% 暖色叠加，铁路线单独提亮到 `#7C6F5F` 并加 0.6px 白描边（铁路是你产品的语义核心，现在它和公路同色）。
   - 暗色：底 `#0B0F0C`，水系 `#0F2A30`，铁路 `#C9A227`（信号金），城市名用 `#C9D1C4`。
   - 加 `landuse`/`park` 一层极淡绿（现在完全没有植被与城市肌理，所以地图「像纸」）。

2. **轨迹三层辉光（P0）**
   ```kotlin
   // 同一份 GeoJSON，加三条 layer（MapLibre 不支持 line-gradient 的稳定动画，
   // 所以用「宽而淡 + 中 + 细而亮」三层静态叠加伪造辉光）
   lineWidth(18f) lineOpacity(0.10f) lineBlur(8f)   // 外辉光
   lineWidth(7f)  lineOpacity(0.28f) lineBlur(2f)   // 中层
   lineWidth(3f)  lineOpacity(1.00f)                 // 亮芯
   ```

3. **当前站呼吸（P0，但只允许一个）**
   MapLibre 没有时间表达式，持续动画只能每帧 `setProperties`。**只对「当前站」这一个点做**，12fps 更新 `circle-radius`（24→34dp）与 `circle-opacity`（0.35→0），其余站点用静态三层静态环。

4. **昼夜色温层（P1，几乎零成本）**
   地图上方盖一层 `Box`，颜色随真实时间在 4 个关键帧之间插值（`LocalTime` 每分钟更新一次，不是每帧）：
   清晨 `#FFB877 @ 8%` → 正午 `#FFFFFF @ 0%` → 黄昏 `#FF7A3D @ 12%` → 深夜 `#0A1B3A @ 18%`。

5. **Header 变成「出发信息牌」**
   现在是一个中性胶囊。改成左侧一条 3dp 的品牌色竖条 + 站名用 tabular 数字对齐的「站台牌」质感；夜里自动切换成「亮灯牌」（`onSurface` 反相 + 外发光）。

6. **主按钮**
   `开始旅程` 是唯一的主操作，现在是一个扁蓝色胶囊。加：① 内高光 + 底部 2dp 暗边（物理厚度）② 按下时文字轻微下压 1dp（不是整体缩放）③ 松手后 120ms 一圈 6% 白色涟漪扩散。

### 5.2 时长/目的地选择（`JourneySelectionContent.kt`、`DestinationList.kt`）

**现状**：中间一个滑杆 + 下方卡片轮播，卡片选中放大 1.02 + 4dp 阴影。方向对，但「换档」这件事没有在世界上发生。

1. **路线生长（P0，签名动效）**
   换时长时，不要直接替换路线，而是：
   - 旧线按 `0.35` 的透明度淡出（`Fast`）
   - 新线从起点开始「生长」到终点（`Scene` 480ms，`LinearOutSlowIn`），生长头部有一枚 6dp 光点
   - 沿线站点依次弹入（`Stagger 28ms`，`Settle` 弹簧，从 0.6 放大到 1）
   - 里程与时间数字 count-up（240ms）
   > 实现建议：**动画期间用 Compose `Canvas` 覆盖层画**（可逐帧插值），动画结束再交回 MapLibre 静态层。避免每帧改 style，也避免闪。

2. **卡片轮播加视差**
   未选中的卡片不要只是「缩小 + 变淡」，加 `translationX` 的 8% 视差与 2° 的 Z 轴旋转，让轮播像一叠实体票卡被翻动。

3. **档位滑杆（`TimeDurationPicker`）**
   现在是刻度 + 手柄。给手柄加：吸附时的 `Settle` 回弹 + 8ms 触感 + 吸附瞬间刻度从手柄向两侧「点亮」（80ms 内以手柄为中心扩散）。

### 5.3 车票打卡（`TicketCheckInScreen.kt`）

**现状**：已经有票滑入、票离场、盖章、脉冲，是全 App 最完整的动效段。问题是没有「材质」。

1. **纸**：票面加一层极轻纸纹（噪点 + 2% 竖向纤维），边缘 0.5dp 内阴影，撕口处加纸纤维毛边。
2. **压印**：站点名用 `BlendMode.Multiply` + 1px 下方白色高光，做出「钢印压进纸里」的感觉。
3. **盖章**：现在是缩放 + 透明度。改成：快速落下（80ms，`d=0.5` 过冲到 1.12）→ 回弹（`Settle`）→ 墨迹 `blur` 从 3px 收敛到 0.4px（120ms）→ 纸张轻微抖动 1.5dp。配振动。
4. **飞入收藏**：盖章后车票缩小并沿贝塞尔曲线飞向右下「我的」，同时首页对应入口做一次 12% 的缩放脉冲。用 `SharedTransition` 的 `sharedBounds` 就能做。

### 5.4 专注页（`FocusSessionScreen.kt` + `FocusComponents.kt`）

**现状**：顶部「正在前往 + 站名 + 座位」、中间巨大倒计时、下方当前站/下一站卡片。信息完备，但**没有「在车上」的感觉**——这和 `IMMERSIVE_JOURNEY_DESIGN.md` 里写的目标有差距。

1. **窗外（P0）**：屏幕顶部 22% 高度做一条「车窗」，内容按速度横向滚动（视差 3 层：远山 0.2x、近景 1x、前景雨滴/尘埃 2x），并随时间改变色温。不需要美术资源：用 3 层不同频率的 `Canvas` 曲线剪影 + 渐变天空就能成立。
2. **速度感**：速度数字从 67 跳到 68 时，数字用 `Stagger` 轻微上移；窗景滚动速度与速度值线性相关（`speed / 300`）。
3. **倒计时**：现在是 `surface.copy(0.68)` + 边框。改成玻璃（L2）+ 数字 `tnum` + 秒变化时**只有变化的那个数字**做 80ms 的 1.06 缩放（不要整块滚）。
4. **进度不要只靠数字**：把「已行进 / 总里程」画成一条细线，火车头图标在线上的位置 = 真实进度，线已走过的部分是品牌色，未走部分是 12% 灰。
5. **减少无限动画**：暂停时的呼吸可以留，但把冒号闪烁、车标脉冲合并成一个「心跳」节奏（同一 `InfiniteTransition` 驱动，相位错开）。

### 5.5 到站（`FocusComponents` 到站卡 + `FocusTimerService` 通知）

- 到站瞬间：地图相机 `zoom +0.6` 并轻微 `tilt`（MapLibre 支持 `tilt`），持续 600ms，然后回正。
- 到站卡从底部弹入时，用 `Settle` 弹簧（现在 `tween(320)`），并让背后的地图做 4% 的缩放「呼吸」。
- 报站音 + 振动 + 车票盖章三者**必须同时**发生（现在是分散的）。多模态同时到达，是「真实发生」的关键。

### 5.6 历史与数据（`AllJourneysScreen.kt`、`DataBottomSheet.kt`）

你已经有点亮省份、城市图鉴、里程成就，但都躺在底部弹层里，而且用 chips 呈现。

1. **铁路星座图（P1，签名视觉）**：把去过的车站按经纬度画成一张暗色星图，站点是星点（去过=亮，没去过=7% 灰），走过的线路是连线。进入时星点依次点亮（`Stagger 12ms`），鼠标/手指按住的站显示名字。不需要省份 GeoJSON，纯经纬度即可，数据你已经全有。
2. **数据页的四种颜色**：里程=品牌绿、城市=信号黄、天数=青、连续=品红（GoLog 的做法），每个数字配一条 2dp 的进度弧。
3. **成就解锁**：从「列表里多一行」变成「全屏 1.2s 的仪式」：暗场 + 光从中心扩散 + 成就名用衬线体 + 一句纪念体文案。

### 5.7 设置 / 引导 / 小组件

- 引导页（`OnboardingScreen.kt`）已有 Pager + 指示器宽度动画，补一个「手绘线条自绘」的插图进场即可（`PathMeasure` 逐段绘制，600ms）。
- 小组件（`FocusTimerWidget.kt`）现在是 Glance 静态文本。至少让「进行中」状态有一个 3 段的进度条，并且每小时刷新时更新一次文案（「已行进 128 公里」）。

## 6. 三个签名记忆点

如果只能做三件事，做这三件——它们会被用户描述给朋友。

### M1 活地图（Living Map）

首页静置 3 秒，屏幕上必须有 3 处缓慢变化：当前站的呼吸环、昼夜色温的漂移、列车在站台上的怠速浮动。
**验收**：录一段 5 秒静置视频，不看 UI 文字，能感觉到「这里有个地方在运行」。

### M2 路线生长（Route Grows）

每次改时长，路线像墨迹一样从你脚下长出去，站点一颗颗亮起，数字跟着跳。
**验收**：连续拖动时长滑杆 10 次，不出现闪烁/跳变，且落地时间 < 520ms。

### M3 铁路星座（Rail Constellation）

「我的」里那张图，把「我去过哪」变成一片会亮的星空。
**验收**：新用户进来是黑的，老用户进来是亮的——**同一张图，两种情绪**，这是最好的留存素材。

> 加分项 M4：**车窗**（专注页那条会动的窗），它把你已有的白噪音/报站音串成一个完整场景。

## 7. 工程落地

### 7.1 性能预算（先立规矩，否则动效会毁掉体验）

- 每屏**同时运行的无限动画 ≤ 1 个**（专注页 ≤ 2）。
- 任何动画不得在 `composition` 阶段读状态：一律 `graphicsLayer { }` / `drawBehind { }`（你已经做对，保持）。
- 地图持续动画：**每帧 `setProperties` 的 layer ≤ 1 个**，且频率 ≤ 15fps。
- 首帧：首页可交互 < 800ms；转场掉帧率目标 < 1%（`FrameMetrics`）。
- 低电量/省电模式：自动降级为「静态光晕 + 无粒子」。

### 7.2 减少动效（必须做，否则一部分用户会晕）

```kotlin
// 尊重系统「移除动画」设置
val reduceMotion = remember {
    Settings.Global.getFloat(context.contentResolver, Settings.Global.ANIMATOR_DURATION_SCALE, 1f) == 0f
}
CompositionLocalProvider(LocalReduceMotion provides reduceMotion) { ... }
```
- `reduceMotion = true` 时：所有无限动画停止、转场改为 120ms 淡入、地图辉光保留但呼吸停止、天气粒子密度降到 0（只保留色调层）。

### 7.3 Compose 侧的关键实现

```kotlin
// 1) 统一按压：替换散落的 6 处 scale 逻辑
fun Modifier.pressScale(
    source: MutableInteractionSource,
    pressedScale: Float = 0.965f,
): Modifier = composed {
    val pressed by source.collectIsPressedAsState()
    val scale by animateFloatAsState(if (pressed) pressedScale else 1f, Motion.press, label = "press")
    graphicsLayer { scaleX = scale; scaleY = scale }
}

// 2) 玻璃层（minSdk 31，真模糊可用）
@Composable
fun GlassSurface(modifier: Modifier = Modifier, content: @Composable () -> Unit) {
    Box(modifier
        .graphicsLayer { /* 由父层提供已模糊的背景副本 */ }
        .background(MaterialTheme.colorScheme.surface.copy(alpha = 0.55f))
        .border(1.dp, Brush.verticalGradient(listOf(Color.White.copy(0.55f), Color.Transparent)), MaterialTheme.shapes.large)
    ) { content() }
}
```

> 关于 `MaterialExpressiveTheme`：项目里的 `material3 1.4.0` **已包含** `MaterialExpressiveTheme` 与 `MotionScheme`（`@ExperimentalMaterial3ExpressiveApi`），切过去能一次性拿到「弹性」的默认组件动效。但它是实验 API，且会改变所有组件的默认手感，**建议在分支上试，不要直接上主干**。若不想冒险，用 §4.1 的 token 手工覆盖关键组件即可获得 80% 效果。

### 7.4 地图侧的取舍

MapLibre 没有时间表达式（无 `["time"]`），所有持续动画都要靠 `setProperties`。因此确立一条架构原则：

> **静态的交给 MapLibre，动态的交给 Compose 覆盖层。**

- 轨迹辉光、站点、暗色样式 → 静态 layer，一次设置。
- 路线生长、列车怠速浮动、光点 → Compose `Canvas` 覆盖层，动画结束再交回。

这样既拿到流畅度，也不会让地图线程变成瓶颈。

## 8. 验收：灵动度评分卡

改造前后各打一次（0–4 分），由 3 个人独立打分取平均。

| # | 检查项 | 判定方法 |
|---|---|---|
| 1 | 静置 3 秒内有 ≥3 处缓慢变化 | 录屏观察 |
| 2 | 任意点击 16ms 内有视觉反馈 | 240fps 录屏 |
| 3 | 60% 以上的转场是「形变/生长」而非「淡入」 | 逐屏走查 |
| 4 | 界面中存在 ≥3 个明确的高度层级 | 关掉颜色只看阴影 |
| 5 | 有 1 个能被用户命名的「角色/物件」 | 5 秒测试后提问 |
| 6 | 有 1 个能被用户主动分享的「实体」 | 访谈 |
| 7 | 高能色面积 ≤ 5% | 取色统计 |
| 8 | 每屏无限动画 ≤ 1 | 代码走查 |
| 9 | 存在 ≥1 个「多模态同时发生」的时刻（视+听+触） | 体验 |
| 10 | 开启「移除动画」后界面仍完整可用 | 系统设置 |

**目标**：从当前约 21/40 提到 33/40。

## 附录 D：专注页去噪已并入统一方案（2026-11-22 第二轮）

参考 FocusFlight（专注飞机，App Store「App of the Day」）、Forest、潮汐后，得到一条总原则：

> **首页可以灵动，专注页必须安静。两者共享同一套材质、色彩与动效 token，但专注页的「变化预算」严格限制在 2 个元素/秒以内。**

| | 首页 / 路线选择 | 专注页 |
|---|---|---|
| 目标 | 灵动、有生命感 | 单焦点、低干扰 |
| 主角 | 地图 + 主按钮 | **剩余时间 + 进度线** |
| 动点 | 呼吸环、生长线、怠速列车 | 列车位置 + 秒数 |
| 控件 | 底部胶囊组 | 边缘玻璃圆，30s 后降到 35% |
| 文字 | 可以有情绪文案 | 只留 1 行语境 + 1 行里程 |
| 色彩 | 品牌绿为主 | 中性为主，无红色警报 |
| 天气 | 可以开 | 默认关，限制在地图区内 |

**专项文档**：`docs/research/FOCUS_SCREEN_DECLUTTER.md`（含 18 类元素清单、三档密度、地图去噪规则、验收清单）。

**关键发现（需优先修复）**：`CountdownDisplay` 与 `RouteProgressionStrip` 在 2.0.1 代码里都已写好但没有接入 `FocusSessionScreen`——专注页中央是空的。任何「灵动化」改造都必须先恢复这个主角，否则所有次要信息会被迫挤到边缘平级竞争。
