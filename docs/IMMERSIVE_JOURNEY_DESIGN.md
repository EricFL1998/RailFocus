# Rail Focus 沉浸式旅行感功能设计方案

## 1. 概述与设计理念

Rail Focus 的核心是将“番茄钟专注”与“中国高铁长途旅行”进行深度意象化绑定。为打破工具类专注软件易枯燥的局限，让每次专注不仅是一串倒计时，而是一场真实而浪漫的铁道漫游，本方案围绕“视觉沉浸”、“长途旅程连贯体验”以及“轻量群体共振”规划三大核心模块，供后续版本演进落地。

---

## 2. 核心功能规划

### 一、 车窗风景动态面板与沿线气候联动

#### 1. 核心交互与视角构图
- **双重视角自由切换**：专注界面支持通过横滑手势或视角微浮钮，在“全景轨迹地图视角”与“第一人称车窗视角”间平滑过渡。
- **车窗画框与动态流动**：以经典高铁宽幅全景车窗及小桌板为前景画框，窗外风景粒子及视差图层随当前列车计算速度向后水平流动，营造贴地飞驰的真实动感。
- **光影与昼夜轮替**：依本地系统时间实时呈现自然光影：
  - 清晨（05:00 ~ 08:00）：柔和晨曦微光；
  - 正午（08:00 ~ 17:00）：明朗通透艳阳；
  - 黄昏（17:00 ~ 19:30）：暖金晚霞微红；
  - 深夜（19:30 ~ 05:00）：沉静夜行星空，并在车窗深色玻璃上反射微弱的车厢内灯光倒影。

#### 2. 地理风貌与场景过渡
- **沿线地域风貌**：依据算法规划的列车实时坐标，匹配中国典型地理画风：
  - 江南水乡：水田倒影、民居白墙青瓦、烟雨连绵；
  - 北方原野：广袤平原、玉米麦田、白桦树林；
  - 西北风光：戈壁丹霞、起伏丘陵；
  - 城市枢纽：高速公路互通、现代化楼宇天际线。
- **长隧道暗黑模式**：计算到列车穿越山区长隧道时，窗外光照自然淡出至纯黑，车厢内转入暖暗光自习环境，给双眼适度放松。

#### 3. 真实气象映射与动态音景
- **实时天气接口联动**：拉取起终点或途径城市实时天气数据（晴、多云、雨、雪、雾）。
- **气象动效与音效**：
  - **雨天**：车窗表面凝结倾斜流淌的水珠，伴随细密真实的雨点打窗白噪音；
  - **雪天 / 雾天**：窗外视野可见度渐变模糊，附带车窗边缘轻微凝霜效果；
  - **晴天**：小桌板与车厢地板投射随速度轻微摆动的阳光光斑。

### 二、 换乘与长途连贯旅程（接力专注模式）

#### 1. 长途干线自动区段拆解
- **长专注跨度拆解**：针对一整天自习、备考或长时段深度办公场景，支持规划一条“跨省超长铁道干线”（如北京西至广州南）。
- **合理分段拆解**：系统自动将几千公里的全程合理切分为多个番茄钟区间（例如：北京西 → 石家庄 → 武汉 → 长沙南 → 广州南）。

#### 2. 站台换乘与候车休息
- **中途站台换乘倒计时**：每一段专注结束列车进站，自动开启“同站台换乘 / 休息时间”（如 5 ~ 15 分钟）。
- **候车室休息氛围**：界面平稳切换至“正在 XX 站候车大厅休息”视听环境，倒计时结束时伴随发车提醒，引导用户开启下一区段的接力专注。

---

### 三、 邻座同行乘客（轻量陪伴感）

#### 1. 车厢同乘与无感陪伴
- **同向旅客状态提示**：在专注界面一角以极度克制的方式呈现：“当前车次有 6 位旅客与你同行”，营造同在一节高铁车厢内各自安静阅卷、办公的自习室氛围。
- **零干扰原则**：完全杜绝文字聊天、弹幕或弹窗等打扰专注的行为，仅以人数数字和静默光标传递陪伴感。

#### 2. 到站致意与正点共享
- **到站平安致意**：到达终点站时展示本次列车共同坚持到底的旅客总数，支持互道系统静默致意（如“击掌庆祝到达”），强化群体自律的心理共鸣。

## 3. 落地实施路线规划（Roadmap）

| 优先级 | 模块名称 | 核心开发内容 | 预期周期 |
| :--- | :--- | :--- | :--- |
| **P2** | **车窗风景动态面板** | 视差滚动车窗构图、昼夜光影切换、隧道暗黑渐变 | 2 个迭代 |
| **P2** | **天气气象与动态音景联动** | 天气 API 接入、车窗水珠雨雪特效、环境白噪音音频流 | 1 个迭代 |
| **P3** | **接力专注（中转换乘）** | 长途干线切片调度算法、同台换乘休息计时体系 | 2 个迭代 |
| **P3** | **邻座同行（车厢陪伴）** | 轻量同乘数据统计与终端渲染、到达致意交互 | 1 个迭代 |
