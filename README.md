# Rail Focus（铁道专注）

看起来是一款高铁旅行应用，其实是一款专注软件。

开启一段专注，就像踏上一趟列车：选择出发城市、设定乘坐时长，Rail Focus 会为你「推荐」这段时间里可以到达的车站。专注结束时，你就「抵达」了目的地——每一段专注都会变成一张车票，记录在你的旅程历史里。

用旅行的仪式感，让专注变得更有盼头。

## 它能做什么

**把专注变成一趟旅程**
设定专注时长，就如同选择乘车时间。时间越长，能「到达」的车站越远。你可以选一座向往的城市作为目的地，专注不再是盯着倒计时硬撑，而是「我在去某个地方的列车上」。

**收获一张车票**
每完成一段专注，就会得到一张车票：起点是开始专注时的车站，终点是这段时间足以抵达的车站，票面还记录着这次专注的时长。车票会保存在行程列表里，积累下来就是你专注过的证明。

**旅程有意外，也有惊喜**
和真实出行一样，旅程也会「晚点」——被打断的专注会如实记录；需要提前结束，也可以「退票」。这些状态都会留在车票上，不会假装完美，但每一段都算数。

**专注计时，后台也稳稳运行**
计时在后台持续运行，切换应用或锁屏都不会中断，并有桌面小组件，不解锁手机就能看到已经专注了多久。

**回头看看走过的路**
所有行程汇成一份完整的历史，配合统计图表，你可以直观地看到自己专注了多少次、累计了多长时间。

**其他贴心之处**

- 应用内置全国 1,400 多个火车站的离线数据，无需联网即可「规划旅程」
- 支持浅色和深色主题
- 首次使用有简单的引导流程，上手没有门槛

## 使用方式

1. 打开应用，选择出发城市
2. 设定专注时长，看看这段时间能「去哪」
3. 选定目的地，开始这趟专注之旅
4. 专注结束，收获车票；中途被打断也可以如实记录

## 获取应用

目前可通过源码自行构建安装：克隆仓库后执行 `./gradlew installDebug`（需要 Android SDK 环境，系统要求 Android 8.0 及以上）。
