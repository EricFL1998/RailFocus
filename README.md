# Rail Focus（铁道专注）

坐高铁的时候，时间常常被白白浪费。Rail Focus 想帮你把这段时间用起来：告诉你这段时间能去哪，陪你记录旅途，还能开启一段专注时光。

## 它能做什么

**想想能去哪**
选一个出发城市，再告诉它你愿意坐多久的车，Rail Focus 会列出这段时间内所有坐高铁能到达的车站。内置数据库收录了全国 1,400 多个火车站，车程计算考虑了加速、减速和沿途停站，不是简单的距离换算，结果更贴近真实出行。

**把旅途变成一张车票**
选定目的地后，行程会以一张车票的形式呈现在首页：起点、终点、预计时长一目了然。列车如果晚点，可以记录延误时间；行程有变，也可以标记退票。所有车票都会保存在行程列表里，随时翻查。

**路上不无聊，专心做自己的事**
上车后开启专注模式，计时器会在后台持续运行，即使切换应用或锁屏也不会中断。专注计时还支持桌面小组件，不解锁手机就能看到已经专注了多久。

**回头看看走过的路**
每次行程都会被记录下来，形成一份完整的历史。配合统计图表，你可以直观地看到自己去了多少地方、花了多少时间在路上。

**其他贴心之处**

- 内置离线地图，基于免费的 OpenStreetMap 数据，不依赖网络也能查看车站位置
- 支持浅色和深色主题，随系统或按个人喜好切换
- 首次使用有简单的引导流程，上手没有门槛

## 使用方式

1. 打开应用，选择你所在的城市（或出发站）
2. 选择愿意乘坐的时长，浏览可达车站
3. 挑一个目的地，开始行程
4. 上车后开启专注模式，下车结束行程

## 获取应用

目前可通过源码自行构建安装：克隆仓库后执行 `./gradlew installDebug`（需要 Android SDK 环境，系统要求 Android 8.0 及以上）。
